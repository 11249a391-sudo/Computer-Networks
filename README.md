# Computer Networks Lab Programs

## About
This repository contains the source code for Computer Networks Laboratory experiments.

## Experiments
1. Basic Network Commands
2. Hostname and IP Address
3. HTTP Web Client using TCP Sockets
4. TCP Echo Client and Server
5. TCP Chat Application
6. File Transfer using TCP Sockets
7. ARP and RARP Simulation
8. Study of Network Simulator (NS2)
9. Congestion Control Algorithms using NS2
10. TCP/UDP Performance using NS2
11. Distance Vector Routing
12. Link State Routing
13. DNS Hostname and IP Address
14. CRC Error Detection
15. Wireshark and Network Analysis / Packet Tracer / LAN Trainer exercises

## Languages and Tools
- Python
- C / C++ (where applicable)
- NS2
- TCL
- Wireshark
- Cisco Packet Tracer

## Purpose
This repository is created for learning and practicing Computer Networks laboratory programs.
